How to publish for free (GitHub Pages)
Step 1 — Go to github.com and create a free account
Step 2 — Create a new repository named ap-chinese-prep (set to Public)
Step 3 — Upload this HTML file and rename it to index.html
Step 4 — Go to Settings → Pages → set source to main branch / root
Step 5 — Your site is live at https://YOUR-USERNAME.github.io/ap-chinese-prep

Tip: Each time you add questions, export the JSON, then re-upload the HTML file (with questions saved in it) to GitHub.
